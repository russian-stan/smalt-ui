# docs

The library documentation site on [VitePress](https://vitepress.dev/): live `<Demo>` examples,
API tables generated from TS types and JSDoc (`vue-component-meta`), and a theme and token showcase.
Private app (not published).

> Part of the **Smalt UI** monorepo. Installation and setup are covered in
> [Getting started → Installation](/guide/getting-started#installation). Start the dev server from
> the repo root with `pnpm dev`.

## Scripts

| Script         | Description                                                                   |
| -------------- | ----------------------------------------------------------------------------- |
| `pnpm dev`     | VitePress dev server (runs `gen:api` first)                                   |
| `pnpm build`   | Static site build (runs `gen:api` first)                                      |
| `pnpm preview` | Local preview of the built site                                               |
| `pnpm gen:api` | Generates `api.json` from the TS types + JSDoc of `@smalt-ui/core` components |

Run from the repo root: `pnpm --filter docs <script>`.

## How it works

- **Component pages**: `components/<name>.md` — intro paragraph → `<Demo>` variations → `## API`
  with `<ApiTable name="SName" />`.
- **Guide**: `guide/*` and `theming.md` (architecture, isolation, theming, icons, i18n, Nuxt).
- **Navigation**: sidebars in `.vitepress/config.ts`.
- **Auto API**: `scripts/gen-api.mjs` extracts props/events/slots with `vue-component-meta` and writes
  `.vitepress/data/api.json` (**git-ignored**, generated by the pre-dev/pre-build hooks). The source
  of truth is the JSDoc in component code (`types.ts`, `defineSlots`, `defineModel`).

## Theme (VitePress)

Site styling customizations live in `.vitepress/theme/` (`style.css` and others). `@smalt-ui/core`
components are registered globally through the `SUI` plugin; demo previews are wrapped in an
`.s-root` container.
